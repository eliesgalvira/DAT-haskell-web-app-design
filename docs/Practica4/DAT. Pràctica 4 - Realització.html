    • Projecte

    El projecte de pràctiques (directori dat-prj) té el paquet forums-app corresponent a la pràctica 4. La descripció d'aquest paquet la podeu veure en el fitxer dat-prj/forums-app/forums-app.cabal i consisteix en l'executable forums-app.

    També podeu navegar pel contingut de la pràctica.

    Se us dona el codi font d'una versió inicial que haureu de completar fins obtenir la funcionalitat demanada. El codi d'aquesta versió inicial és compilable. Això vol dir que, un cop creada la base de dades, ja podeu provar l'aplicació.

    Per compilar i executar l'aplicació caldrà que feu:

    ~$ cd dat-prj/forums-app
~/dat-prj/forums-app$ stack run forums-app -- PORT

    on PORT és el port HTTP pel qual el servidor accepta connexions.

    Creació de la base de dades

    En aquesta pràctica usarem una base de dades SQLite. Per administrar la base de dades es disposa de sqlite3 que és un programa interactiu que accedeix al fitxer indicat (o el crea si no existia) i espera sentències SQL.

    Per a l'aplicació dels forums, el SQL per crear la base de dades el teniu distribuït en 3 fitxers del directori dat-prj/forums-app/sqlite:

    • schema.sql Aquest SQL crea les taules necessàries del model (users, forums, topics i posts).
    • users-data.sql Insereix les dades dels usuaris.
    • forums-data.sql Insereix les dades d'un fòrum per poder començar a fer proves.

    Decidiu on voleu ubicar el fitxer de base de dades i des del terminal crideu el programa sqlite3, passant-li com argument el nom del fitxer de base de dades i injectant-li a l'entrada el corresponent SQL. Per exemple:

    
~/dat-prj/forums-app$ sqlite3 forums.db < sqlite/schema.sql
~/dat-prj/forums-app$ sqlite3 forums.db < sqlite/users-data.sql
~/dat-prj/forums-app$ sqlite3 forums.db < sqlite/forums-data.sql
    Cal tenir en compte que per poder accedir la base de dades des l'aplicació cal definir la variable forumsDbName del mòdul Forums.Config (fitxer dat-prj/forums-app/src/Forums/Config.hs) amb el path del fitxer de base de dades.

    Codi font

    El codi font de la pràctica es troba en el directori dat-prj/forums-app/src del projecte i està format per 9 mòduls. Les dependències entre aquests mòduls les podeu veure amb el següent diagrama:

    Cadascún d'aquests mòduls conté les següents funcionalitats:

    Main
    És el punt d'inici del servidor Warp i conté l'adaptació de l'aplicació (amb interface WAI) al servidor.
    Forums.App
    És el punt d'entrada de l'aplicació DatFw. Conté el codi corresponent a la inicialització i a l'enrutament de l'aplicació.
    Forums.Handler
    És pròpiament el controlador de l'aplicació. Conté el codi corresponent al processat de les peticions.
    Forums.View
    Conté el codi corresponent a la generació de les vistes (HTML).
    Forums.Found
    Defineix els tipus i les instàncies fonamentals per a l'us de DatFw en aquesta aplicació.
    Forums.Config
    Variables de configuració de l'aplicació.
    Forums.Model
    En aquest mòdul es defineixen les entitats de l'aplicació que es guarden en la base de dades. En aquesta pràctica tenim 4: usuaris, fòrums, topics i posts. És independent dels aspectes tant de controlador com de les vistes.
    Db
    Aquest mòdul ofereix al model una interfície per accedir la base de dades que estalvia l'us de SQL en la definició del model. Tot el SQL queda encapsulat dins d'aquest mòdul.

    Aquests mòduls s'hauran de completar de manera que la funcionalitat de l'aplicació sigui com l'especificada en l'enunciat.

    Fonaments

    En el mòdul Forums.Found del codi proveit s'ha definit el tipus del lloc de ForumsApp i les instàncies de les classes fonamentals de DatFw. El tipus ForumsApp conté la informació a nivell d'aplicació que en aquesta pràctica serà la connexió amb la base de dades. (aquesta informació serà accessible des dels handlers amb la funció getSite).

    L'aplicació s'accedeix amb URLs que tenen la forma 

    http://HOST:PORT/path-info?query-string
    on el path-info determina la ruta de l'aplicació (en aquesta aplicació no usarem el query-string per a determinar la ruta).

    La instància de HasRoute defineix el tipus de les rutes Route ForumsApp i les funcions de conversió entre les rutes definides i el path-info més el query-string. En el codi proveit s'han definit les següents rutes:

    RutaPath-infoContingut de la resposta
    HomeR / Pàgina principal de l'aplicació.
    ForumR fid /forums/fid Pàgina que mostra el fòrum amb identificador fid
    TopicR tid /topics/tid Pàgina que mostra la qüestió (topic) amb identificador tid.
    LoginR /login Autenticació d'usuari i inici de sessió autenticada.
    LogoutR /logout Tancament de sessió autenticada.

    La funció renderRoute fa la conversió de ruta a path-info i query-string, mentre que la funció parseRoute fa la conversió inversa de path-info i query-string a ruta. Ambdues estàn definides per la instància de la classe HasRoute per al tipus ForumsApp.

    La conversió de segment a valor del paràmetre es fa amb la functió fromPathPiece de la classe PathPiece (s'ha definit la instància de PathPiece per als tipus de paràmetres usats en aquesta aplicació).

    En el mòdul Forums.Found també s'ha definit la instància de la classe WebApp per al tipus ForumsApp. Aquesta classe defineix algunes funcionalitats bàsiques de l'aplicació i en el nostre cas no redefinim cap dels valors per defecte definits en la classe.

    Inici i enrutament

    El mòdul Forums.App conté la inicialització de l'aplicació i l'enrutament de les peticions.

    La inicialització consisteix en primer lloc en la creació del valor de ForumsApp amb tota les dades gobals a la aplicació. En aquesta aplicació, aquesta dada és únicament una conexió amb la base de dades.

    Un cop construit el valor de ForumsApp s'usa la funció toApp que obté una aplicació WAI a partir de la funció d'enrutament. Aquesta funció determina quin handler executarà partir de la ruta i el mètode HTTP de la petició.

    En el mòdul Forums.App usarem la funció toApp de la següent forma:

    toApp ForumsApp{ forumsDb = db } $ \ route ->
    case route of
        patró-de-ruta -> selectMethod
            [ onMethod "mètode" handler
            , ...
            ]
        ...

    El sistema d'autenticació

    Una autenticació bàsica dels usuaris (mecanismes de login i logout) ja es dona feta. Veieu en el mòdul Forums.Found funcions per obtenir l'usuari autenticat en la sessió actual, i en el mòdul Forums.Handler els handlers corresponents a les accions de login i logout.
