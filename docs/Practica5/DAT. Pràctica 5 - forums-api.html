API del servei de fòrums

El servei és accedit amb URLs que tenen la forma http://localhost:5001/api/PATH_INFO on el PATH_INFO, mètode HTTP i els continguts JSON de petició i resposta es descriuen en la següent taula.

/PATH_INFO Mètode HTTP
/user GET
Descripció
Obté informació de l'usuari autenticat en la sessió
Resposta JSON
{ name: MBUNAME }
/forums GET
Descripció
Obté la lista de fòrums
Resposta JSON
{ items: [ FORUM, ... ] }

on s'han usat variables per als paràmetres:

  • fid: FID
  • tid: TID
  • pid: PID

i variables per als tipus següents:

  • MBUNAME = Null (si no s'ha autenticat en la sessió) ó USERNAME (nom de l'usuari autenticat)
  • USERNAME = String
  • URL = String
  • FID, TID, PID = Number
  • DATE = String (dia i hora en format ISO-8601)
  • MARKDOWN = String (text Markdown)
  • FORUM = { id: FID, selfLink: URL, moderator: USERNAME, title: String, category: String, description: MARKDOWN, created: DATE, topicsLink: URL, topicsCount: Number, postsCount: Number, lastPosted: DATE, lastPostLink: URL or Null, lastPostUser: USERNAME }
  • TOPIC = { id: TID, selfLink: URL, forumLink: URL, user: USERNAME, started: DATE, title: String, postsLink: URL, postsCount: Number, firstPostLink: URL, lastPostLink: URL, lastPosted: DATE, lastPostUser: USERNAME }
  • POST = { id: PID, selfLink: URL, topicLink: URL, user: USERNAME, posted: DATE, message: MARKDOWN }
